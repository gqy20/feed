# 思源字体

简体中文区域子集，使用 Adobe 官方可变 TrueType WOFF2 文件；保留原始字体文件名与随附 SIL Open Font License。

- 思源黑体：[Source Han Sans](https://github.com/adobe-fonts/source-han-sans)，`release/Variable/WOFF2/TTF/Subset/SourceHanSansCN-VF.ttf.woff2`
- 思源宋体：[Source Han Serif](https://github.com/adobe-fonts/source-han-serif)，`release/Variable/WOFF2/TTF/Subset/SourceHanSerifCN-VF.ttf.woff2`

字体从本站加载，使用 `font-display: swap`，字体加载期间显示系统字体。思源黑体用于界面，阅读区固定使用 18px 思源宋体，不提供字体设置。
